## Cosa è il catalogo CPV
I codici CPV (Common Procurement Vocabulary) sono un sistema di classificazione unico europeo per standardizzare la descrizione di beni, lavori e servizi negli appalti pubblici, servono a rendere più trasparenti le gare, facilitare la ricerca di opportunità commerciali per le imprese e migliorare la concorrenza transfrontaliera unificando la terminologia in tutte le lingue UE. Si tratta di una struttura gerarchica (ad albero) di codici numerici, con un vocabolario principale (8 cifre + 1 di controllo) e uno supplementare per dettagli aggiuntivi, utilizzato dalle Pubbliche Amministrazioni per identificare l'oggetto degli appalti.

L'elenco è tratto dal sito web acquistinretepa.it a dicembre 2025. Database fonte: file denominato Copertura merceologica codici CPV_27 Novembre 2025
